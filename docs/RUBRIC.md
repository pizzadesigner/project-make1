# Transferability rubric

`transferability_score` answers one question: **how easily could another
European city copy this project?** It is scored 0–100 as the sum of five equally
weighted criteria (0–20 each). A high-impact project that needed a lagoon or a
canal should score _lower_ than a modest one any city could replicate.

| Criterion                    | 0–20                            | What it measures                                           |
| ---------------------------- | ------------------------------- | ---------------------------------------------------------- |
| **Capital cost**             | 20 = low, 0 = very high         | Up-front budget relative to a mid-sized city's means.      |
| **Institutional simplicity** | 20 = one authority, 0 = many    | Number of bodies and approvals needed to deliver it.       |
| **Context independence**     | 20 = generic, 0 = site-specific | Reliance on unusual geography, existing assets or climate. |
| **Evidence base**            | 20 = measured results, 0 = none | Whether outcomes are documented and sourced.               |
| **Time to first result**     | 20 = fast, 0 = decade+          | How quickly a copy would show benefits.                    |

The score is shown on the map and the city view with this rubric one click away,
so a planner sees _why_ a project is (or is not) easy to adopt — not just a
number floating in a card.
